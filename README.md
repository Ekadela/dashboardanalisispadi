# Interactive Dashboard for East Java Rice Production Analysis (2018–2025)

An interactive web-based dashboard for analyzing rice production trends in East Java Province from 2018–2025. This project was developed to transform statistical agricultural data into more informative, interactive, and easy-to-understand visualizations.

The dashboard presents yearly production trends, regional production distribution, top-producing districts, and district-level trend analysis to support data-driven insights in the agriculture sector.

---

## Dashboard Overview

This dashboard provides several interactive visualization features, including:

- Total rice production statistics
- Production growth comparison between years
- Interactive rice production trend charts
- Regional production distribution map
- Top 10 rice-producing districts/cities
- District-level production trend analysis
- Automatic statistical insights
- Responsive web-based interface

## Features

### KPI Cards
Displays important statistical indicators such as:
- Total rice production in 2025
- District with the highest production
- Percentage change from the previous year

### Production Trend Analysis
Interactive charts showing rice production trends in East Java from 2018–2025.

### Interactive Production Map
Geographical visualization of rice production distribution across districts/cities in East Java.

### Top 10 Producing Districts
Bar chart visualization of districts with the highest rice production in 2025.

### District Trend Exploration
Users can select districts to analyze yearly production trends interactively.

### Automatic Insights
Summary of statistical findings generated from the dataset to simplify data interpretation.

## Dataset

The dataset used in this project contains rice production statistics from districts/cities in East Java Province during 2018–2025.

Data Source:
- Badan Pusat Statistik (BPS) East Java Province
